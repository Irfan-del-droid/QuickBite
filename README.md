# QuickBite

South Indian Restaurant Management & Online Food Ordering System.

### Modules:
- **Authentication Module (RRN 1246)**: Registration and Login (`login.html`, `register.html`, `js/auth.js`)
- **Food Catalogue & Shopping Cart (RRN 1247)**: Menu display and Cart (`menu.html`, `cart.html`, `js/menu.js`, `js/cart.js`)
- **Admin Module (RRN 1260)**: Restaurant Admin Portal (`admin.html`, `css/admin.css`, `js/admin.js`, `js/storage.js`)
